How to use WHM

  1. Type a website in the box at the top (or Import list).
  2. Press Check and wait for the scan to finish.
  3. Click a row to open full-screen problems and fixes.
  4. Use ← All websites to go back to your full list.

Scroll the table to see every website. The list is never cut off on purpose.
