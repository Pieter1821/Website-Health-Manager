Get started

Quick check

  1. Type a website at the top (example: mybusiness.co.za).
  2. Press Check and wait for it to finish.
  3. Click the row to open Problems & fixes.
  4. Press ← All websites to go back to the full list.

Many websites at once

  1. Use any Excel/CSV that has real website addresses (e.g. example.com or https://…). Extra columns are fine — WHM finds the URL column automatically.
  2. Click Import list and choose the file.
  3. Open a site and press Check again, or press Check all to scan every site one by one.

What the colours mean

  • Looks good (green) — fine (certificate/domain more than 30 days out).
  • Worth a look (amber) — still works; renew soon (14–30 days left on certificate or domain).
  • Needs a fix (red) — under 14 days, expired, or the site won’t open.
  • Couldn’t finish (grey) — timeout or network glitch; try again.

Useful buttons

  • Excel / CSV — saves one site’s report into Downloads.
  • Export all — one Excel for every website (Overview + Problems).
  • Remove all — clears every website from the list (asks first).
  • Status chips and All customers — quick filters. Click column titles to sort.
  • i on a column — short plain-English explanation.
  • Settings — wait time, auto checks, alert webhooks.
  • Updates — checks GitHub for a newer installer (also runs quietly when the app opens).

The list sorts worst-first by default. Status covers Opens, SSL, domain, and DNS.
